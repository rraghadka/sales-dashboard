# Sales Dashboard

This project is an Interactive sales dashboard built with HTML, CSS, and JavaScript using CSV (Excel-exported) data, featuring filters, KPIs, charts, and dark mode.

## Features
- Displays total revenue, orders, and average order value
- Filters by city and branch
- Search functionality for product lines
- Interactive charts (Bar, Pie, Line) using Chart.js
- Dark mode toggle
- Animated UI and loading spinner

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Data Source
The data was originally provided in Excel format and converted to CSV (`supermarket_sales.csv`) for processing in JavaScript.
